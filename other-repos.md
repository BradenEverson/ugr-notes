# List of All Repositories Relevant to this UGR Project

- [Thoth](https://github.com/BradenEverson/thoth): Minimal RTOS with swappable schedulers
- [Thoth-Testbench](https://github.com/BradenEverson/thoth-testbench): Thoth implementation for Stm32 with Tracing Heuristics
- [Aza](https://github.com/BradenEverson/aza): Python script for reading CSV data from Thoth-Testbench
- [TinyLR](https://github.com/BradenEverson/tinylr): TinyML Implementation of a Logistic Regression Runtime
