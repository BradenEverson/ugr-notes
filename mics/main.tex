    \maketitle

    \begin{abstract}
        This is the abstract of the paper. Note that the title and the abstract are the only things on the title page. This example shows two authors at different institutions. If information is the same for multiple authors, the authors can be listed together under the same institutional information. The abstract should be 150 words or less and provides a concise summary of the paper's main contributions and findings.
    \end{abstract}

    \section{Level 1 Header}

    This is the first section of the paper. It starts on a new page. Note how the left/right justification appears: text is justified on the left as well as on the right. This section cites a paper by Author A \cite{authorA}. It then cites a paper by Author B \cite{authorB}. The citations are clearly described in the reference section. Note that citation format can be determined by the author. This is only one example.
